🛒 Retail POS System - Engineering Assessment

This project is a full-stack Point of Sale (POS) application built to demonstrate backend robustness, high-concurrency management, and transactional integrity. It was developed as part of the Software Engineering Internship assessment for Micronsoft Solutions.  

🧠 Engineering Approach & Problem Solving

Rather than just building a basic UI, I focused on solving real-world retail challenges such as race conditions and data consistency.  
1. Handling High-Demand Flash Sales (Challenge 01)

  The Problem: 
     In high-traffic scenarios (like a flash sale), hundreds of requests can hit the server at the exact same millisecond, potentially causing stock to drop below zero (Race Condition).  

  My Solution: I implemented Row-Level Locking using Django’s .select_for_update().  
  How it works: When a transaction starts, the database "locks" the specific product row until the stock is updated and the transaction is committed. Other requests wait in a queue, ensuring 100% accurate stock levels.  
  
  Verification: Included a load_test.py script that simulates 100 concurrent threads to prove the logic holds up under pressure.  
  
2. Scalable Analytics with Big Data (Challenge 02)

   The Problem: Querying daily revenue from a table with 100,000+ records can become slow and lag the dashboard.  
   
   My Solution: I optimized the database by adding an Index to the created_at field.     
   
   Result: Even with the 100,000 dummy records generated by my populate_data.py script, the analytics API responds in less than 500ms.  
   
3. Guaranteeing Data Integrity (Challenge 03)
   
   The Problem: If a customer buys 5 items but only 4 are saved due to a crash, the inventory becomes desynced.  
   
   My Solution: Wrapped the checkout logic in transaction.atomic.  
   
   Reliability: This ensures an "all-or-nothing" approach—if one part of the order fails, the entire transaction rolls back, keeping the data clean.  
   
   Bonus: I also designed a specialized Receipt Component strictly formatted for 80mm thermal printers.  
   
🛠️ Tech Stack & Setup
   
   Backend: Python (Django REST Framework)  
   Frontend: React.js  
   Database: MySQL  
   
Installation
   Backend: 
      Install requirements: pip install -r requirements.txt  
      Setup MySQL in settings.py and run python manage.py migrate  
      Run server: python manage.py runserver  
      
   Frontend:
      cd pos-frontend -> npm install -> npm start  
      
🧪 Testing the System
   Generate 100k Records: 
      python populate_data.py  
   Run Concurrency Test: 
      python load_test.py
